# 專賣街 Combo Finder for Dream Town Story

An unofficial fan tool for Kairosoft's *Dream Town Story*. Tap a shop to see every combo (專賣街) it belongs to, with land and price bonuses, the space each combo needs, and a planner that finds the smallest layout for several combos together.

- 186 combos and the sizes of 150 buildings
- Space planner: shares buildings between combos, keeps doors (short side) on a road, lets decorations sit inside a block
- English, 日本語, 繁體中文, 简体中文, 한국어 (non-English names are unofficial translations)
- One self-contained HTML file that works offline
